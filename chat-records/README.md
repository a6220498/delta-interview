## 為什麼要有這份索引

題目要求「在相關程式碼區段加入 `// [AI assisted {chat-number}]` 註解，並將對話紀錄存放在
以該對話編號命名的位置」。程式碼裡的編號要能查得到對應的對話，才有意義；這份表就是那個
對照關係。
